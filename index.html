Seleksi Ribuan Foto Cepat & Otomatis Tanpa Upload

Membantu fotografer & kreator menyeleksi gigabyte foto dalam hitungan detik. Algoritma komputer vision lokal mendeteksi foto blur (Laplacian 3x3), eksposur gelap/terang, serta kelompok foto duplikat/mirip (dHash 64-bit) langsung di memori browser.

1

Pilih Folder Foto

Pilih direktori foto Anda (JPG, PNG, WebP). Aplikasi membaca file secara streaming tanpa mengunggah ke internet.

2

Analisis Otomatis

Sistem mendeteksi tingkat ketajaman, rentang kecerahan, dan kemiripan burst-shot menggunakan Web Worker.

3

Pisahkan ke Folder

Review hasil, sesuaikan ambang sensitivitas secara live, dan salin otomatis ke folder Keep, Blur, Gelap, atau Duplikat.

Catatan: HEIC dan RAW belum didukung browser native. Gunakan Chrome atau Edge desktop. File asli Anda tidak pernah diubah atau dihapus sama sekali (proses ekspor hanya membuat salinan baru).
